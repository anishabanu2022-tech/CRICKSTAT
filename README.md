# 🏏 CRICKSTAT - Salesforce Cricket Management System

A Salesforce-based application to manage Cricket Players, Teams, and their Match Performances efficiently.

### ✨ Features & Objects
* **Players__c:** Stores player details like Name, Age, Role, Jersey Number, and Team.
* **Team__c:** Manages Team information, Coach, and Home Ground.
* **Match_Performance__c:** Tracks individual player performance per match - Runs, Wickets, Strike Rate.
* **Data Integrity:** Implemented Validation Rules and Formula Fields to maintain data accuracy.

### 🛠️ Tech Stack
* Salesforce Custom Objects & Fields
* Apex Classes & Triggers
* SOQL & SOSL
* VS Code, Salesforce CLI, Git & GitHub
